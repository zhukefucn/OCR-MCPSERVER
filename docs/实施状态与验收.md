## 发布门禁

后续版本必须保持：

1. 本机目标测试和全量测试通过。
2. Git 工作区干净。
3. 明确提交同步到 Ubuntu。
4. 远程镜像构建成功。
5. 容器启动并进入 `healthy`。
6. REST、MCP 和真实文件回归成功。
7. 下载产物通过 ZIP、路径、条目、大小和 `final.md` 校验。
8. 记录不可变镜像标签和镜像 ID。

## 后续需求

Stage 0 输入预处理已经完成架构决策和原型验证，仍需在正式接入时重点确认：

- `source_page_count` 与 `prepared_page_count` 的数据契约。
- 长图派生页与方向恢复的页码映射。
- 文档级方向纠正与少量异常页重试的边界。
- 预处理清单和重试复用规则。

该需求不得与本次产物打包修复混在同一个实现提交。
